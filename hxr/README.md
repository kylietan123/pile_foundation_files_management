# 桩基工程全过程管理文档平台

面向桩基工程的全过程文档管理平台：多账号登录、项目管理（增删改查）、按「七个阶段」分类归档文档、文件上传 / 下载 / 删除。

## 技术栈

- 后端：Node.js + Express
- 数据库：SQLite（使用 Node 内置 `node:sqlite`，无需安装任何原生编译依赖）
- 文件存储：本地 `uploads/` 目录
- 前端：原生 HTML / CSS / JavaScript，无构建步骤

## 快速开始

需要已安装 Node.js（18.13 及以上，推荐 22+）。

```bash
npm install
npm start
```

启动后浏览器访问 <http://localhost:3000>。

> 修改端口：`PORT=8080 npm start`（Windows PowerShell 用 `$env:PORT=8080; npm start`）。

## 同事如何补充「工程设计阶段」和「桩基施工阶段」

只需编辑 **`config/stages.js`** 一个文件，把对应阶段的 `parties` 数组填上即可，无需改动代码或数据库。保存后重启服务即生效。

以「工程设计阶段」为例，把：

```js
{ id: 4, name: '工程设计阶段', owner: '吴双', parties: [] }
```

改成：

```js
{
  id: 4,
  name: '工程设计阶段',
  owner: '吴双',
  parties: [
    {
      name: '工程设计单位',
      docs: [
        { name: '桩基设计任务书、桩基设计技术要求', type: '报告' },
        { name: '桩基平面布置图、桩身结构图', type: '图纸' }
        // …… 对照《桩基工程全过程管理文档清单.txt》继续补全
      ]
    },
    {
      name: '政府审查单位',
      docs: [
        { name: '桩基施工图审查合格书', type: '报告' }
      ]
    }
  ]
}
```

字段说明：

- `name`：参与单位名称
- `docs`：该单位需提交的文档类型数组
  - `name`：文档类型名称
  - `type`：文档分类标签（如 `报告` / `图纸` / `证照` / `照片/视频` / `模型`，仅用于展示）

## 权限说明

- 普通账号只能查看、修改、删除**自己创建**的项目及其文档；
- 管理员可查看并操作**全部**账号的项目，并可管理账号（重置密码 / 删除账号）；
- 注册面向所有访问者开放；如要限制注册，可自行关闭注册接口。

## 常见问题

- **文件存在哪里？** `uploads/<项目ID>/` 目录，删除项目或文档会同步删除对应文件。
- **如何备份？** 复制 `data/`（数据库）和 `uploads/`（文件）两个目录即可。
- **忘记密码？** 可联系管理员在「用户管理」中重置密码；管理员本人忘了密码则需在 `data/app.db` 中重建账号。
